# AGENTS.md — правила для агентов (Codex и др.)

«Ось Browser» — приватный деловой браузер с изолированными профилями. Владелец пишет по-русски;
отвечать ему **по-русски, коротко, простыми словами**: что сделано, ссылка на сборку, готовность в %.
Подробное состояние и история — `docs/HANDOVER.md` (прочитать целиком перед работой).

## Части репозитория
| Папка | Что | Эталон / ТЗ |
|---|---|---|
| `app/` | Android (Kotlin, Mozilla GeckoView, без XML-разметки: UI в коде) | `docs/SPEC.md` |
| `desktop/` | Windows (Electron + TypeScript) | `docs/SPEC_WINDOWS.md`, очередь `docs/DESKTOP_TASKS.md` |
| `site/` | Сайт os-browser.com (Astro) | `docs/SPEC_SITE.md`, сервер `docs/SPEC_SERVER.md` |
| `docs/play/` | Материалы Google Play (16 языков) | `docs/play/README.md` |

Android — эталон поведения: Windows повторяет его по `docs/WINDOWS_SYNC.md` (§1–§23).

## Последние решения владельца (07.11.2026; приоритет над прежними правилами)
- Последнее уточнение владельца: субагенты остановлены, корневая сессия работает сама. Прежнее распределение семи ролей ниже — история, не разрешение запускать их снова.
- GitHub Actions **вообще не использовать**. Запущенные сессией проверки остановлены.
  Сборки и проверки выполнять в доступном локальном/контейнерном окружении.
  Не запускать workflow; не отправлять изменения, которые автоматически запускают Actions.
  До отдельного изменения этого решения новые GitHub-коммиты должны предотвращать запуск CI.
- Разрешён собственный сервер для добровольной синхронизации Android ↔ Windows:
  профили, сохранённые логины/пароли, избранное, заметки; содержимое шифруется на устройстве.
- Разрешена панель владельца со статистикой сервиса и обезличенной статистикой функций
  браузера **только с согласия пользователя**, с возможностью отзыва. Адреса страниц,
  поисковые запросы, пароли, содержимое заметок и избранного в аналитику не включать.
- Действует запрет на рекламу и сбор аналитики без согласия. См. SPEC_SYNC.md и SPEC_ADMIN_PANEL.md.
- Владелец назначил роли: архитектура, безопасность, логика, аудит, два исполнителя правок,
  приёмка. Корневая сессия отвечает за выпуск; субагенты не публикуют и не сливают изменения.

## Жёсткие правила (решения владельца)
1. **Без рекламы и сбора данных без согласия.** По умолчанию данные остаются на устройстве.
   Владелец разрешил отдельный сервер добровольной синхронизации; содержимое хранилищ
   шифруется на устройстве. Разрешена панель владельца и обезличенная статистика функций
   только с отдельным согласием пользователя. Конкретные границы — SPEC_SYNC.md и SPEC_ADMIN_PANEL.md.
   Не отправлять личное содержимое или статистику сторонним сервисам.
2. **Языки — 16**, порядок столбцов во всех `Tr*.kt`: en, ru, es, pt, fr, de, ar (RTL), hi, tr, zh,
   be, uz, ky, tg, kk, hy (`Tr.SUPPORTED`). Новая строка — сразу на все 16. Строки Windows — тоже в
   `app/src/main/java/ru/multibrowser/TrDesktop.kt` (Windows берёт их через `desktop/scripts/gen-i18n.mjs`).
3. **Термины — только из `docs/GLOSSARY.md`** (одно понятие — один термин на всех платформах и в магазине).
   Тест `GlossaryTest` это проверяет; запрещённые синонимы перечислены там же.
4. Неизменяемое: «Ось» / «Ось Browser», названия продуктов, адреса, подстановки `%s %d %1$d`.
5. Задачи со статусом `[!]` и решения из `docs/SPEC_WINDOWS.md` §9 — только владелец. Сомнение — спросить.
6. Секреты не печатать и не коммитить. Ключ подписи — только защищённые секреты окружения сборки (`OS_KEYSTORE*`); не хранить открытый ключевой файл в репозитории.
7. Не ослаблять тесты и не отключать проверки ради зелёного прогона.
   Запрет GitHub Actions означает перенос проверок в локальное окружение, а не отмену проверок.

## Сборка и проверки
**GitHub Actions запрещены последним решением владельца.** Не запускать workflow,
не скачивать артефакты через Actions, не повторять прогоны. Исторические workflow оставлены
как описание прежних проверок, их наличие не разрешает запуск.

**Android — локально/в контейнере:** JDK 17, Android SDK для compileSdk проекта,
`./gradlew testDebugUnitTest assembleDebug --no-daemon`. Номер ручного APK задаётся `OS_BUILD_NUMBER`. Сверять XML test-results.
Приёмка — на устройстве/локальном эмуляторе; фиксировать непроверенные сценарии.
Рабочий SDK сессии: `/workspace/work/android-local/sdk` (платформа android-37.0);
Docker-прокси и CA настраивать по инструкции окружения, TLS-проверки не отключать.
CLI Android запускать с `--no-metrics`; эмулятор — с `-no-metrics`.
Переводы: `python3 docs/i18n-new/check.py` (PASS).

**Windows:** `cd desktop && npm ci && npm run check`; локальная Electron-приёмка.
Без реального Windows-прогона не объявлять проверенными специфичные для Windows сценарии.
**Сервис/панель:** `cd server && npm ci && npm test && npm run test:ui`;
Chromium/Playwright — локально. Не подменять живую синхронизацию библиотечными тестами.

## Ветки, коммиты, слияние
- Android: ветка `feat/quick-search`; Windows: `feat/desktop-<задача>`; сайт: `feat/site-*`.
- В `main` — только после зелёных юнит-тестов **и** зелёной локальной приёмки: `git merge --no-ff`.
  Новые GitHub-коммиты должны содержать `[skip ci]`; новую ветку создавать сразу на таком
  коммите, не промежуточным ref на старый коммит, способный запустить workflow.
  Релизы сейчас готовит корневая сессия вручную, без Actions. Личный ключ подписи
  использовать только через защищённый секрет окружения, не раскрывать и не заменять новым ключом.
- Не переписывать историю `main`, не force-push в общие ветки.
- Каждую правку Android, которую должен повторить Windows, — новым параграфом в `docs/WINDOWS_SYNC.md`
  и задачей в `docs/DESKTOP_TASKS.md`.
- GitHub из облачных сессий — только REST (`gh api ...`), GraphQL может быть недоступен.

## Где что в Android-коде
- `BrowserActivity.kt` — браузер, вкладки, меню ⋮ (`BrowserMenu.kt`), меню ссылки (`LinkMenu.kt`, `Snack.kt`).
- `Gecko.kt` — движок, сессии по профилям (изоляция cookies через contextId).
- `Tr*.kt` — переводы; `Tabs.kt`, `Pins.kt`, `Profiles.kt`, `Bookmarks.kt`, `Passwords.kt`, `Downloads.kt` — данные.
- Тесты: `app/src/test/java/ru/multibrowser/` (JUnit, без устройства); сценарии — `.github/scripts/*.sh`.
