# Конвейер агентов для Windows-версии (desktop/)

Утверждено владельцем 31.10.2026. Задачи берутся из `docs/DESKTOP_TASKS.md` в порядке очереди ниже.
Агенты работают **строго по одному**; главная сессия (координатор) запускает следующего, когда закончил предыдущий.

## Шаги на одну задачу
1. **architect** — проект задачи → `<папка задачи>/1-architect.md`.
2. **coder** — код в ветке `feat/desktop-<slug>` → `<папка задачи>/2-coder.md`.
3. **security** — проверка безопасности → `<папка задачи>/3-security.md` (ОК / замечания).
4. **reviewer** — проверка кода → `<папка задачи>/4-review.md` (ОК / замечания).
   Замечания 3–4 → снова coder (не больше двух кругов, потом задача `[!]`).
5. **acceptance** — `npm run check`, приёмка, новые сценарии и скриншоты → `<папка задачи>/5-acceptance.md`.
6. **builder** — push ветки, зелёный CI на windows-latest, слияние в main, релиз → `<папка задачи>/6-build.md`.

Папка задачи: `/tmp/claude-0/-home-user-browser/20532046-4076-58d0-935c-3df15386d4e7/scratchpad/pipeline/<slug>/`.
Каждый агент сначала читает все предыдущие файлы этой папки.

## Общие правила (для всех агентов)
- Репозиторий: `/home/user/browser`, код в `desktop/`. Работать в этой же папке (агенты идут по одному).
- Без своих серверов, аналитики и рекламы; ничего не отправлять на сторонние сервисы без решения владельца.
- Решения из `docs/SPEC_WINDOWS.md` §9 и задачи `[!]` — только владелец. Сомнение → остановиться и написать в отчёт.
- Секреты не трогать, не печатать, не коммитить.
- Новые строки интерфейса — в `app/src/main/java/ru/multibrowser/TrDesktop.kt` на все 16 языков (+RTL), 6 тем.
- Каждая функция — с тестом (unit и/или сценарий в `desktop/test/acceptance.mjs`) и скриншотом.
- Правила безопасности Electron — `docs/SPEC_WINDOWS.md` §7.
- Коммиты на русском, в конце:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01LhBUsR7YHqmY1HZXZ1PCiE
  ```
  Идентификатор модели нигде не писать.
- В main — только builder и только после зелёного CI.
- Проверки: `cd /home/user/browser/desktop && npm run check`;
  приёмка: `cd /home/user/browser/desktop && xvfb-run -a node /home/user/browser/desktop/test/acceptance.mjs`.
- GitHub: только REST (`gh api ...`), GraphQL недоступен.
