# Звонок при переходе в другое приложение

Запрос владельца 07.11.2026: голосовой режим ChatGPT прерывается, когда «Ось Browser» уходит в фон.

## Изменение

`BackgroundCalls` подключает `GeckoSession.MediaDelegate` к обычным и приватным сессиям.
Служба `MicrophoneCallService` работает только при фактическом состоянии RECORDING микрофона
и наличии системного RECORD_AUDIO; разрешение сайта само по себе не запускает службу.
В manifest объявлены FOREGROUND_SERVICE, FOREGROUND_SERVICE_MICROPHONE и тип службы microphone.
Служба не экспортируется, не перезапускает запись после уничтожения процесса (START_NOT_STICKY).
При записи вкладка защищена от выгрузки кэшем, движку передаётся PRIORITY_HIGH. После остановки
приоритет возвращается к обычному. Приложение не выдаёт себе разрешения и не обходит AppLock.

Уведомление содержит общий текст без адреса сайта, профиля, имени или содержимого разговора.
Возврат к звонку не передаёт URL и сохраняет живую приватную вкладку. Кнопка завершения
привязана к конкретной сессии: устаревшее действие не завершает другой звонок.
Для гарантированной остановки захвата эта кнопка закрывает сессию страницы звонка;
при следующем открытии страница загружается заново. Cookies и сохранённые данные не очищаются.
При закрытии/очистке вкладки, выходе из инкогнито, событии остановки микрофона и обработанном
сбое сессии запись исключается из реестра; когда записей нет, служба завершается.
Если Android не разрешил запуск фоновой службы, показывается сообщение оставить страницу открытой;
текущий звонок в видимом приложении не закрывается только из-за отказа запуска службы.

Новые строки — TrExtras.kt, 16 языков, термин завершения звонка закреплён в GLOSSARY.md.
Это аудиосценарий: фоновые права камеры и обход ограничений батареи не добавляются.
Серверов, отправки содержимого разговора и аналитики эта правка не добавляет.

## Подтверждённые проверки

Свежий локальный JDK17/SDK37.0: testDebugUnitTest + assembleDebug PASS, 2412 тестов,
0 failures/errors/skipped. Тестовый APK311 (`ru.multibrowser.test`), существующий тестовый ключ.
Первый прогон был заблокирован недоступным lock-файлом Robolectric в /home/agent;
повтор выполнен с отдельным Java user.home для тестов внутри workspace, проверки не отключались.
Проверка переводов docs/i18n-new/check.py PASS.

`BackgroundCallsTest`: foreground-уведомление, отсутствие URL в возврате, приватность,
отзыв RECORD_AUDIO, адресное завершение и безвредность устаревшей кнопки.
`CaptureRegistryTest`: независимые звонки, очистка последнего захвата, идемпотентность,
отсутствие активного звонка для неактивного устройства.

## Приёмка перед выпуском

Ещё не подтверждено на современном физическом Android с реальным ChatGPT:
- разрешить микрофон, начать голосовой режим, перейти в другое приложение на 60с;
- проверить, что собеседник слышит речь, ответ слышен, соединение не прерывается;
- вернуться из уведомления без повторной загрузки и нового запроса микрофона;
- закончить звонок на сайте и из уведомления: микрофон/служба должны остановиться;
- проверить инкогнито, переключение профилей, блокировку экрана, отказ микрофона,
  отозванное разрешение и запрет уведомлений, несколько параллельных записей;
- зафиксировать штатное прерывание системой при конкурирующем использовании микрофона.

Локальный эмулятор с виртуальным аудио проверяет только механизм, не качество разговора.
До такой приёмки не объявлять проблему ChatGPT полностью решённой и не сливать в main.
