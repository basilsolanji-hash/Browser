# Скачок текста при прокрутке — 07.11.2026

Запрос владельца: при прокрутке страницы пальцем текст смещается дальше ожидаемого.
В setBarsHidden панели переводились в GONE прямо на MOVE: LinearLayout менял размеры
и положение GeckoView, а сайт мог дополнительно пересчитывать вложенные scroll-контейнеры.

Автоматическое скрытие теперь использует ChromeVisibility.autoHidden и INVISIBLE.
Размер области страницы остаётся прежним. Компромисс явно сохранён: место скрытых панелей
зарезервировано, автоматическое скрытие не добавляет площади чтения. Явный полный экран
обрабатывается отдельно. Настройки и содержимое профилей не изменяются.

Проверка: ChromeViewportTest строит настоящую Android-компоновку с прокручиваемым текстом,
запоминает границы viewport и scrollY, затем трижды скрывает/возвращает панели. Геометрия
и позиция сохраняются. Локальные Gradle unit+assembleDebug: PASS, 2394 теста,
0 failures/errors; тестовый APK 310. GitHub Actions не использовались.

Реальная приёмка жеста на современном Android-устройстве ещё не выполнена.
APK пока не опубликован: uploads.github.com возвращает 401 для настроенной авторизации.
В main эта правка не объединена.
