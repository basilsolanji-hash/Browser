# Быстрый поиск: WINDOWS_SYNC §9

Ветка feat/desktop-home-search. Как MainActivity.quickSearch на Android: запрос или адрес,
выбор профиля, новая вкладка по Enter/кнопке. По умолчанию выбран последний профиль,
на чистой установке — первый. Ввод не теряется при выборе профиля; после успеха очищается.
Используются существующие address_hint, qs_go, qs_pick_profile на всех 16 языках.

Главный процесс валидирует профиль и адрес. Если профиль уже открыт в другом окне,
запрос получает именно это окно; чужой профиль не подменяется. Заблокированное целевое
окно не получает переход. Инкогнито отказывает. Подсказок/сети во время ввода нет.
