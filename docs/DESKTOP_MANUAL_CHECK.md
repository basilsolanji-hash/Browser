# Ось для Windows: ручная проверка (то, что нельзя проверить в CI)

## Windows Hello и шифрование паролей (DPAPI)

Нужен компьютер с Windows 10/11, где настроен Windows Hello (PIN, отпечаток или лицо).

1. Установите Ось из последнего релиза (`Os-Browser-Setup-….exe`), откройте профиль «Личное»,
   войдите на любом сайте и нажмите «Сохранить» в вопросе «Сохранить пароль для …?».
2. Меню ⋮ → «Личный кабинет» → у сохранённого пароля ⋮ → «Показать пароль».
   Ожидается окно Windows Hello. После подтверждения пароль показан, после «Отмена» — не показан.
   То же для «Копировать пароль».
3. Откройте `%APPDATA%\Os Browser\passwords.json` в Блокноте: пароля открытым текстом там нет
   (поле `p` — длинная строка base64).
4. Скопируйте `passwords.json` на другой компьютер или в другую учётную запись Windows и положите
   в ту же папку: Ось не должна показать пароль, потому что DPAPI привязан к учётной записи.
   Сайт и логин видны, пароль — нет. Резервная копия `.osbackup` при этом восстанавливается по своему паролю.
5. Если Windows Hello не настроен (Параметры → Учётные записи → Варианты входа), «Показать пароль»
   работает без запроса — как на Android без отпечатка.

Результат пришлите сообщением: номер шага и что увидели (скриншот, если что-то не так).
