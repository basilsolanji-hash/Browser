# WINDOWS_SYNC §17: выделение без прыжков

Ветка feat/desktop-selection-stability. В Windows панели уже фиксированы по высоте;
добавлен недостающий реальный регрессионный сценарий вместо вызовов addNote/searchText.

Проверяется настоящее выделение перетаскиванием мыши, неизменные границы WebContentsView
шапки и страницы во время удержания, прокрутка без потери выделения, правая кнопка
и контекстные действия. Через CDP доставляется touchStart: подтверждается, что страница
получила событие, 750 мс удержания и touchEnd не меняют границы панелей. Это проверка
удержания пальцем; сценарий не выдаёт её за физический тест конкретного сенсорного экрана.

Локально lint PASS, test/selection.mjs — 10 PASS. Снимки mouse-selection.png и touch-hold.png.
Оба Windows workflow запускают сценарий и публикуют снимки. Windows CI ожидается,
поэтому задача ещё не [x]. Новых строк интерфейса нет.
