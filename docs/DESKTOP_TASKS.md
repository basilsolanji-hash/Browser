# Задачи для версии Windows (desktop/)

Сюда главная сессия Android-приложения (и пользователь) пишет функции, которые нужно сделать
в Windows-версии, чтобы ПК не отставал от телефона. Сессия Windows (session_01LhBUsR7YHqmY1HZXZ1PCiE)
проверяет этот файл каждый час, берёт задачи сверху вниз, делает их в ветках feat/desktop-*,
вливает в main после зелёной приёмки на windows-latest и отмечает здесь результат.

Можно и сообщением: send_message на session_01LhBUsR7YHqmY1HZXZ1PCiE.

## Формат
```
- [ ] Короткое название
  Что: что должно работать (как на Android: какой файл/экран — эталон).
  Приоритет: высокий | обычный
```
Статусы: `[ ]` — новая, `[~]` — в работе (ветка), `[x]` — сделано (версия/релиз), `[!]` — нужен ответ.

## Задачи
<!-- новые задачи — сюда, сверху -->
Сравнение с Chrome (31.10.2026): чего нет в Оси.

- [ ] Перенос из Chrome: закладки, пароли, история
  Что: закладки — файл HTML (экспорт Chrome) или прямо из профиля Chrome; пароли — CSV из
  chrome://password-manager; история — из профиля Chrome. Без сети, всё локально.
  Приоритет: высокий
- [ ] Картинка в картинке
  Что: кнопка на видео и пункт меню — видео в отдельном маленьком окне поверх всех.
  Приоритет: обычный
- [ ] QR-код страницы
  Что: кнопка в адресной строке — QR текущего адреса, генерация локально (без сервиса).
  Приоритет: обычный
- [ ] Снимок страницы целиком
  Что: снимок видимой части и всей страницы в PNG, сохранение в загрузки.
  Приоритет: обычный
- [ ] Инструменты разработчика (F12)
  Что: F12 / Ctrl+Shift+I открывают DevTools для вкладки; выключаемо в настройках.
  Приоритет: обычный
- [ ] Вход по ключу доступа (passkey)
  Что: WebAuthn на сайтах через Windows Hello.
  Приоритет: обычный
- [!] VPN-расширения (chrome.proxy)
  Что: Electron не поддерживает chrome.proxy. Варианты: прокси на профиль в настройках
  (HTTP/SOCKS5) и/или «Установить в Ось» на странице Chrome Web Store. Нужен выбор владельца.
  Приоритет: высокий
- [!] Трансляция на телевизор (Cast)
  Что: в Electron нет Cast; возможен только DLNA для видео. Нужен ответ владельца, делать ли.
  Приоритет: обычный
- [!] Перевод страниц
  Что: у Chrome — через серверы Google. Правило «без чужих серверов» → только локальный
  переводчик (большая модель на диске, сотни МБ) или открытие страницы в выбранном сервисе
  по кнопке. Нужен выбор владельца (§9).
  Приоритет: обычный
- [!] Синхронизация между устройствами
  Что: у Chrome — через аккаунт Google. Своих серверов нет → варианты: файл .osbackup
  в своей папке облака (OneDrive/Яндекс Диск) с автоэкспортом, или прямая связь ПК↔телефон
  в одной сети. Нужен выбор владельца (§9).
  Приоритет: обычный
- [ ] Две вкладки рядом (разделение окна)
  Что: открыть вторую вкладку справа в том же окне, ползунок ширины, обмен местами, закрыть половину.
  Приоритет: обычный
- [ ] Установка сайта как приложения
  Что: по manifest сайта — ярлык на рабочем столе/в Пуске, отдельное окно без адресной строки.
  Приоритет: обычный
- [ ] Автозаполнение карт и адресов
  Что: сохранение и подстановка адресов и банковских карт; номер карты зашифрован, показ по PIN.
  Приоритет: обычный
- [ ] Диспетчер задач (Shift+Esc)
  Что: список вкладок и расширений с памятью и процессором, кнопка «Завершить».
  Приоритет: обычный
- [ ] Чтение страницы вслух
  Что: голоса Windows (speechSynthesis), пауза/скорость, подсветка читаемого абзаца; работает и в режиме чтения.
  Приоритет: обычный
- [ ] Безопасный DNS (DNS-over-HTTPS)
  Что: выбор провайдера (выкл / Cloudflare / Quad9 / свой адрес) в настройках приватности.
  Приоритет: обычный
- [ ] Управление звуком из панели
  Что: кнопка на панели, когда где-то играет звук: пауза/дальше, название, переход к вкладке.
  Приоритет: обычный
- [ ] Гостевой режим
  Что: временный профиль без истории и данных, удаляется при закрытии окна.
  Приоритет: обычный
- [ ] Калькулятор в адресной строке
  Что: ввод выражения (2+2, 15% от 300) — ответ в подсказках, Enter копирует результат.
  Приоритет: обычный
- [ ] Настройка шрифтов страниц
  Что: размер шрифта по умолчанию, минимальный размер, шрифты с засечками/без/моноширинный.
  Приоритет: обычный
- [ ] Свои горячие клавиши
  Что: список действий с клавишами в настройках, переназначение, сброс, проверка конфликтов.
  Приоритет: обычный
- [ ] Субтитры к видео (локально)
  Что: распознавание речи в видео на устройстве, без сети; модель скачивается по согласию.
  Приоритет: обычный
- [ ] Дублировать вкладку
  Что: пункт в меню вкладки и Alt+Shift+D — копия с историей «назад/вперёд».
  Приоритет: обычный
- [ ] Перетащить вкладку в отдельное окно
  Что: вытащить вкладку за пределы полосы — новое окно; перетащить обратно — вернуть.
  Приоритет: обычный
- [ ] Панель закладок
  Что: строка закладок под адресной строкой (Ctrl+Shift+B), папки выпадающим списком.
  Приоритет: обычный
- [ ] Тёмная тема для любых сайтов
  Что: принудительно тёмные страницы (выкл/вкл/по теме системы), исключения по сайту.
  Приоритет: обычный
- [ ] Автопрокрутка средней кнопкой
  Что: нажать колесо на странице — значок, движение мыши прокручивает.
  Приоритет: обычный
- [ ] Сведения о сайте
  Что: по замку в адресной строке — сертификат, cookies и разрешения этого сайта, очистка данных сайта.
  Приоритет: обычный
- [ ] Печать с предпросмотром
  Что: своё окно предпросмотра (PDF страницы): страницы, поля, ориентация, фон, «Сохранить в PDF».
  Приоритет: обычный
- [ ] Режим курсора (F7)
  Что: перемещение по тексту страницы стрелками, выделение Shift+стрелки.
  Приоритет: обычный
- [ ] Спрашивать, куда сохранять
  Что: настройка «Всегда спрашивать место загрузки» и «Сохранить как…» в меню загрузки.
  Приоритет: обычный
- [ ] Ссылка на выделенный текст
  Что: пункт контекстного меню — ссылка с #:~:text=…, страница открывается с подсветкой этого места.
  Приоритет: обычный
- [ ] Масштаб для каждого сайта
  Что: Ctrl+плюс/минус запоминается для сайта; список сайтов с масштабом в настройках, сброс.
  Приоритет: обычный
- [ ] Превью вкладки при наведении
  Что: карточка с заголовком, адресом и картинкой страницы; выключаемо.
  Приоритет: обычный
- [ ] Быстрый поиск по сайту из адресной строки
  Что: ключевые слова для поисковиков/сайтов («yt котики»), список и правка в настройках.
  Приоритет: обычный
- [ ] Кнопка «Домой»
  Что: показывать/скрывать кнопку, выбор домашней страницы (стартовая или свой адрес).
  Приоритет: обычный
- [ ] Открыть закрытое окно
  Что: Ctrl+Shift+T после закрытия окна возвращает окно со всеми вкладками; список в истории.
  Приоритет: обычный
- [ ] Пометка «скачано из интернета»
  Что: Mark-of-the-Web (Zone.Identifier) на загрузках, чтобы Windows/SmartScreen предупреждали при открытии.
  Приоритет: высокий
- [ ] Масштаб интерфейса и высокая контрастность
  Что: размер интерфейса браузера 90–150%; поддержка контрастных тем Windows (forced-colors).
  Приоритет: обычный
- [ ] Горячие клавиши расширений
  Что: commands из manifest (_execute_action и свои), назначение клавиш на странице расширений.
  Приоритет: обычный
- [ ] Доступ расширений к сайтам
  Что: для каждого расширения — везде / на выбранных сайтах / только по клику.
  Приоритет: обычный
- [ ] Показ экрана на сайтах
  Что: getDisplayMedia (Meet, Zoom, Телемост) — своё окно выбора: весь экран / окно / вкладка, со звуком;
  разрешение «Показ экрана» в разрешениях сайта.
  Приоритет: высокий
- [ ] Устройства для сайтов (USB, HID, Serial, Bluetooth, MIDI)
  Что: окно выбора устройства, решение запоминается по сайту; по умолчанию — спрашивать.
  Приоритет: обычный
- [ ] Страница ошибки сертификата
  Что: понятная страница с причиной, «Назад» и «Перейти на свой риск» (на сессию); не для HSTS-сайтов.
  Приоритет: высокий
- [ ] Настройки сайта: JavaScript, картинки, звук, всплывающие окна
  Что: добавить в разрешения сайта (по сайту и по умолчанию), как в Chrome.
  Приоритет: обычный
- [ ] Оформление режима чтения
  Что: шрифт (с засечками/без), размер, ширина строки, фон (светлый/сепия/тёмный); запоминается.
  Приоритет: обычный
- [!] Отправить ссылку на телефон
  Что: без своих серверов — только QR-код или связь ПК↔телефон в одной сети. Нужен выбор владельца.
  Приоритет: обычный
- [!] Проверка паролей на утечки
  Что: нужен внешний сервис (haveibeenpwned, k-анонимность: уходит 5 символов хеша).
  Нарушает «без чужих серверов» — нужен выбор владельца (§9).
  Приоритет: обычный
- [!] Поиск по картинке
  Что: как Google Lens — нужен внешний сервис (открыть картинку в выбранном поиске по кнопке).
  Нужен выбор владельца (§9).
  Приоритет: обычный
