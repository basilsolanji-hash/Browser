# Передача дел: «Ось Browser» (Android) — для новой сессии

Репозиторий **basilsolanji-hash/Browser**. Рабочая ветка Android — `feat/quick-search` (всё
проверенное уже в `main`). Последний выпущенный APK — **build-225**:
https://github.com/basilsolanji-hash/Browser/releases/download/build-225/Os-Browser-build-225.apk

## Состояние
- Android готов по коду на ≈98%: приёмка зелёная, юнит-тесты 1991/1991, матрица сценариев —
  части 1, 2, 4 без провалов; часть 3 (живые сайты) упирается в эмулятор: после ~20 тяжёлых
  страниц зависает программный GPU, остальные сайты помечаются «пропущен» (не ошибка приложения).
- Windows ведёт отдельная сессия на другом аккаунте (ветки `feat/desktop-*`), связь — через
  PR [#1](https://github.com/basilsolanji-hash/Browser/pull/1); список правок для неё —
  `docs/WINDOWS_SYNC.md` (§1–§21). Готовы у неё §2, §4, §5, §7, §8, §10, §11, §14, §16, §19, §20,
  исправления безопасности; осталось §1, §3, §6, §9, §12, §13, §15, §17, §18, §21.
- Сайт и сервер — ТЗ `docs/SPEC_SERVER.md` (VPS Beget 5.35.86.240, домен os-browser.com).
- Google Play — все материалы в `docs/play/` (описания на 10 языках, анкеты, значок, баннеры,
  скриншоты 3:4 телефона и планшета на 10 языках, инструкция публикации).
- Ежедневная автопроверка (scheduled task «Ось: ежедневная проверка») **выключена** по просьбе
  владельца; подписка на PR #1 снята.

## Незаконченная задача: 6 новых языков
Белорусский (be), узбекский (uz), кыргызский (ky), таджикский (tg), казахский (kk), армянский (hy)
— интерфейс (601 строка) и 300 фраз. Всё лежит в `docs/i18n-new/`:
- готово: `tr_uz.json`, `tr_ky.json` (601 строка, проверены), фразы `phrases_uz/ky/be/kk.txt`
  (по 300), словари терминов `glossary_uz.json`, `glossary_ky.json`;
- **нужно перевести**: `tr_be.json`, `tr_kk.json`, `tr_tg.json`, `tr_hy.json`, фразы
  `phrases_tg.txt`, `phrases_hy.txt`, словари `glossary_be/kk/tg/hy.json`. Исходник —
  `source.json` (ключ → en, ru) и `phrases_source.tsv`. Правила: сохранять подстановки
  (%s, %d, %1$d…), «Ось», названия продуктов, адреса; короткие подписи — короткими;
  **одна и та же терминология во всех строках** (см. ниже). Проверка — `check.py`.
- подключение: `python3 docs/i18n-new/merge.py` дописывает 6 значений в конец каждой строки
  `Tr*.kt` (порядок be, uz, ky, tg, kk, hy) и кладёт фразы в `app/src/main/assets/phrases/`.
  Затем в `Tr.kt`: `CODES`, `NAMES` (Беларуская, Oʻzbekcha, Кыргызча, Тоҷикӣ, Қазақша, Հայերեն),
  `idx` (be=10 … hy=15), списки поддерживаемых языков в `apply()`; в тестах `TranslationsTest`
  10 → 16 и список языков фраз; в `scenarios.sh`/`store_shots.sh` — список языков `idx`;
  подписи скриншотов `docs/play/tools/captions.json` и описания магазина — на новые языки.
- раздел для Windows в `docs/WINDOWS_SYNC.md` (те же строки и фразы).

## Терминология — держать всегда (требование владельца)
Одно понятие — один термин во всех строках и на всех платформах. Сделать `docs/GLOSSARY.md`:
понятия (профиль, вкладка, группа вкладок, набор вкладок, избранное, скачанные файлы, заметки,
сохранённые страницы, пароли, личный кабинет, настройки, история, инкогнито, разрешения сайтов,
резервная копия, папка, вход/выход, стартовая страница, адресная строка, поисковая система,
конфиденциальность) × 16 языков — значения брать из канонических ключей `Tr*.kt` (`profiles`,
`tabs`, `tab_sets`, `favorites`, `dl_title`, `notes`, `saved_pages`, `passwords`, `cabinet`,
`settings`, `history`, `incognito`, `site_permissions`, `backup`…). Добавить юнит-тест, что
словарь совпадает с этими ключами, и правило: новые строки (Android, Windows, сайт, магазин)
используют только термины словаря.

## Как работать (как было принято)
- Сборка только в CI: `build.yml` (юнит-тесты + APK), приёмка `gh workflow run acceptance.yml
  --ref <ветка>`, матрица 500+ сценариев `git push -f origin HEAD:test/scenarios`, скриншоты
  магазина `git push -f origin HEAD:test/store-shots`; результаты — ветки `*-results-*`.
- В `main` — только после зелёной приёмки (merge --no-ff); релиз `build-N` появляется сам.
- Каждую правку Android дописывать в `docs/WINDOWS_SYNC.md` и сообщать в PR #1.
- Коммиты заканчивать строками Co-Authored-By и Claude-Session своей сессии, модель не писать.
- Владельцу — по-русски, коротко, со ссылкой на APK и готовностью в %; на вопросы решать логично.
