# Передача дел: «Ось Browser» (Android) — для новой сессии

Репозиторий **basilsolanji-hash/Browser**. Рабочая ветка Android — `feat/quick-search` (всё
проверенное уже в `main`). Последний выпущенный APK — **build-246**:
https://github.com/basilsolanji-hash/Browser/releases/download/build-246/Os-Browser-build-246.apk

## Состояние
- Android готов по коду на ≈98%: приёмка зелёная, юнит-тесты 1991/1991, матрица сценариев —
  части 1, 2, 4 без провалов; часть 3 (живые сайты) упирается в эмулятор: после ~20 тяжёлых
  страниц зависает программный GPU, остальные сайты помечаются «пропущен» (не ошибка приложения).
- Windows ведёт отдельная сессия на другом аккаунте (ветки `feat/desktop-*`), связь — через
  PR [#1](https://github.com/basilsolanji-hash/Browser/pull/1); список правок для неё —
  `docs/WINDOWS_SYNC.md` (§1–§23). Готовы у неё §2, §4, §5, §7, §8, §10, §11, §14, §16, §19, §20,
  исправления безопасности; осталось §1, §3, §6, §9, §12, §13, §15, §17, §18, §21, §22, §23.
- Сайт и сервер — ТЗ `docs/SPEC_SERVER.md` (VPS Beget 5.35.86.240, домен os-browser.com).
- Google Play — все материалы в `docs/play/` (описания на 16 языках, анкеты, значок, баннеры,
  скриншоты 3:4 телефона и планшета на 16 языках, инструкция публикации).
- Ежедневная автопроверка (scheduled task «Ось: ежедневная проверка») **выключена** по просьбе
  владельца; подписка на PR #1 снята.

## Сделано: 6 новых языков и словарь терминов
- Белорусский (be), узбекский (uz), кыргызский (ky), таджикский (tg), казахский (kk), армянский (hy):
  все 655 строк `Tr*.kt` (столбцы 11–16) и 300 фраз (`app/src/main/assets/phrases/`). Список языков —
  `Tr.SUPPORTED` (из `Tr.CODES`), от него idx, язык системы, тесты. Заготовки и проверка —
  `docs/i18n-new/` (`source.json` покрывает все ключи, `check.py`, `merge.py` — для следующих языков).
- Магазин: `docs/play/listing-{be,uz,ky,kk,hy}.md` (+ `listing-tg.md` для сайта: таджикского в Play нет),
  баннеры, подписи скриншотов, съёмка скриншотов на 16 языках (`store-shots.yml`, 5 групп).
- **Словарь терминов `docs/GLOSSARY.md`** (25 понятий × 16 языков + запрещённые синонимы), тест
  `GlossaryTest` сверяет его с каноническими ключами. Новые строки на любой платформе — только
  по словарю; новый язык — сначала строка словаря.
- Windows — `docs/WINDOWS_SYNC.md` §22. Сайт (`site/`, своя i18n на 10 языков) — новые языки ещё не добавлены.

Одно понятие — один термин во всех строках и на всех платформах: см. `docs/GLOSSARY.md`.

## Что нужно от владельца
1. Аккаунт разработчика Google Play (25 $) → публикация по `docs/play/README.md`; закрытый тест
   12 тестировщиков × 14 дней.
2. Пополнить баланс Beget и запустить сессию по `docs/SPEC_SERVER.md` (сайт, политика по ссылке).
3. Почта hello@os-browser.com — должна принимать письма.
4. Проверить на телефоне: звук в видео, микрофон, камеру, вход по отпечатку.
5. Windows: подпись кода, Microsoft Store; проверить Windows Hello по чек-листу Windows-сессии.

## Как работать (как было принято)
- Сборка только в CI: `build.yml` (юнит-тесты + APK), приёмка `gh workflow run acceptance.yml
  --ref <ветка>`, матрица 500+ сценариев `git push -f origin HEAD:test/scenarios`, скриншоты
  магазина `git push -f origin HEAD:test/store-shots`; результаты — ветки `*-results-*`.
- В `main` — только после зелёной приёмки (merge --no-ff); релиз `build-N` появляется сам.
- Каждую правку Android дописывать в `docs/WINDOWS_SYNC.md` и сообщать в PR #1.
- Коммиты заканчивать строками Co-Authored-By и Claude-Session своей сессии, модель не писать.
- Владельцу — по-русски, коротко, со ссылкой на APK и готовностью в %; на вопросы решать логично.
