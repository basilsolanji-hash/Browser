# Сайт: 16 языков — локальная подготовка 07.11.2026

Ветка: feat/site-six-languages. База: main f42cfe3. Публикации в main пока нет.

## Изменения

- Добавлены be, uz, ky, tg, kk, hy: 264 ключа в каждом словаре, без подстановки русского
  или английского текста вместо отсутствующих переводов. Основа продуктовых описаний —
  docs/play/listing-<язык>.md; навигационные и установочные подписи переведены отдельно.
- Термины — docs/GLOSSARY.md; проверка запрещённых синонимов читает непосредственно этот файл.
  Старое английское Bookmarks заменено на Favorites. Количество языков обновлено во всех словарях.
- Новые языки больше не переадресуются на русский. Сохранённый выбор имеет приоритет.
  Региональные теги и 404 поддерживают новые языки. Только арабский остаётся RTL.
- Общий LANGS используется генератором страниц, меню, hreflang, sitemap, строками приложения,
  OG и пресс-китом. Сборка даёт 128 языковых страниц + корень + 404 = 130.
- Добавлены 6 OG-картинок и по 3 реальных снимка Windows на каждом новом языке.
- Для kk/ky/tg добавлены локальные подмножества расширенной кириллицы Unbounded и Inter.
  Кириллические языки загружают правильный шрифт; армянский использует системный.
- Никаких новых серверов, сторонних скриптов, аналитики, cookies и внешних шрифтов.
  Служебная телеметрия Astro отключена в CI. Lighthouse сохраняет отчёты на файловую систему.
