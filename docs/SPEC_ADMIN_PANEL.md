# Панель владельца и добровольная аналитика — согласованный состав

Решения владельца 07.11.2026: нужна панель управления с аналитикой; помимо статистики
сервиса разрешена обезличенная статистика использования функций браузера с согласия пользователя.
GitHub Actions запрещены. Реализация и проверка выполняются без них.

## Панель управления
- Отдельная авторизация владельца; обычные пользователи не имеют доступа к панели и её API.
- Показатели сервиса: число аккаунтов и устройств, объём зашифрованного хранилища,
  успешные/неуспешные синхронизации, состояние сервиса. Состав личного хранилища не раскрывается.
- Сводная статистика функций за выбранный период. Пустые состояния отличать от нулевого
  значения; при недоступности сервера показывать ошибку, не подставлять демонстрационные числа.
- Администрирование аккаунта не даёт владельцу сервиса ключ расшифрования данных пользователя.
- Все строки на 16 языках, термины GLOSSARY.md, арабский интерфейс RTL.

## Согласие и границы данных
- По умолчанию отправка статистики функций выключена. Отказ не мешает работе браузера
  или синхронизации. Требуется отдельное, понятное согласие; его можно отозвать в настройках.
- При отзыве прекращается отправка и удаляется локальная неотправленная очередь.
  Уже обезличенные общие счётчики невозможно связать с пользователем для выборочного удаления;
  это нужно прямо объяснить в политике, без обещания удалить несуществующую персональную связь.
- Не собирать в инкогнито, до согласия или после отзыва. Не переносить согласие автоматически
  на другое устройство либо другой аккаунт. Новое назначение/расширение данных требует нового согласия.
- Сервер принимает только заранее разрешённые идентификаторы функций и счётчики,
  а не произвольные события/свойства. Отклонять лишние поля, неверные значения и слишком большие пакеты.
- Исключить URL/домены, заголовки страниц, поисковые запросы, логины, пароли, тексты заметок,
  содержимое избранного, имена файлов, точные координаты и постоянные идентификаторы устройства.
- Не хранить IP в аналитике и журналах доступа. Ограничение частоты запросов может использовать
  временное состояние в памяти, которое не попадает в аналитические данные и резервные копии.
- Сохранять сводные счётчики по периоду/функции/платформе; не сохранять историю действий
  конкретного пользователя. Не показывать в панели детальные группы с малым числом участников.
- Без Google Analytics, Firebase Analytics, сторонних пикселей и рекламных SDK.

## Защита и приёмка
- HTTPS, защищённые сессии владельца, защита от CSRF, ограничение попыток входа,
  безопасное завершение сессий и запрет кеширования ответов с данными.
- Проверки: отказ/отзыв/инкогнито не отправляют статистику; очередь очищается; лишние поля
  и личные данные отклоняются; роли разграничены; панель корректно работает без данных
  и при ошибке API; локализация 16 языков/RTL; счётчики соответствуют реальным данным сервиса.
- Обновить политику конфиденциальности, материалы магазина и описание согласия до включения функции.

очередь с согласием и хранилище агрегатов реализованы локально в `server/`;
