# Ось для Windows: правки, которые надо повторить из Android-версии

Для сессии, которая ведёт настольную версию (`desktop/`, Electron + TypeScript).
Android-версия — эталон. Ниже все правки Android после выхода ТЗ (`docs/SPEC_WINDOWS.md`),
которые нужно сделать и в Windows: по каждой — что должно получиться и как проверить.
Правила те же: всё локально, без своих серверов и аналитики, 10 языков + RTL, 6 тем.
Ветку делать от свежего `main`, в `main` вливать только после зелёного CI и проверки.

## 1. Меню ⋮ как в Chrome
- Карточка у правого верхнего угла (не во весь экран), прокручивается, если выше окна.
- Сверху ряд круглых кнопок без подписей (подпись во всплывающей подсказке и для
  экранного диктора): Назад, Вперёд, В избранное (звезда, переключатель),
  Сохранить страницу, Обновить. Назад/Вперёд неактивны, если идти некуда.
- Ниже группы с иконками, между группами — линия:
  1. Новая вкладка · Новая вкладка инкогнито · Новая группа вкладок
  2. История · Очистить данные · Разрешения сайтов
  3. Скачанные файлы · Избранное · Вкладки · Сохранённые страницы · Заметки
  4. Масштаб
  5. Поделиться · Найти на странице · Режим чтения · Копировать ссылку ·
     Открыть в другом браузере · Версия для ПК / мобильная (с галочкой) · Полный экран
  6. Настройки · Справка и отзывы · Диагностика
  7. «Сделать браузером по умолчанию» — только если Ось ещё не браузер по умолчанию.

## 2. Найти на странице
Панель сверху: поле, счётчик «3 из 12» («Нет совпадений»), стрелки ↑ ↓, закрыть.
Ctrl+F открывает, Enter/Shift+Enter — следующее/предыдущее, Esc закрывает
(`webContents.findInPage` / `stopFindInPage`).

## 3. Панель адресной строки (при фокусе и вводе), как в Chrome
- **Слева в строке** при вводе — кружок с первой буквой выбранного поисковика (его цвет:
  DuckDuckGo #DE5833, Startpage #6573FF, Brave #FB542B, Google #4285F4, Bing #008373,
  Яндекс #FC3F1D); без фокуса — замок у HTTPS.
- **Справа** — крестик «Очистить», когда в строке есть текст.
- **Пустой ввод**: карточка текущей страницы (буква сайта, заголовок, адрес; кнопки
  Поделиться, Копировать ссылку, Изменить адрес), ниже до 8 плиток частых сайтов профиля
  по истории — круг с буквой, подпись = последний заголовок страницы сайта (не домен).
- **При вводе**: скруглённая карточка с разделителями. Первая строка — сам запрос (поиск
  или переход по адресу). Дальше: прошлые поисковые запросы из истории (по адресам
  страниц результатов поисковиков: `q`, `query`, для Яндекса `text`), затем избранное и
  история (до 6). У каждой строки, кроме первой, стрелка ↖ «Подставить в строку».
- Иконки сайтов — буквы в кружках, из сети ничего не грузим (приватность).
- Проверка: юнит-тест разбора запроса из адреса — DuckDuckGo `?q=hello+world` → «hello
  world», Яндекс `?text=…&lr=213` → запрос, `google.com/maps?q=` → не запрос, пустой `q` → нет.

## 4. Скачанные файлы
- Экран «Скачанные файлы» как в Chrome: поиск, «Очистить», строка свободного места на
  диске; фильтры-чипы Все · Изображения · Аудио · Видео · Документы · Другое; группы
  «Только что», «Сегодня», «Вчера», дата.
- Идущая загрузка — кольцо прогресса, «осталось N с/мин», «X из Y», отмена.
- Меню строки: Открыть · Открыть с помощью · Показать в папке · Поделиться · Удалить.
- **Открытие**: PDF, картинки, текст открываются во вкладке Оси; остальное — системным
  приложением по типу (тип по расширению, если сервер прислал `application/octet-stream`).
- Разрешение на скачивание для сайта: «Спросить» по умолчанию (Разрешить / Запретить /
  Запомнить для сайта). Пока вопрос висит, файл качается во временную папку, чтобы не
  потерять; «Запретить» — удаляем. Заблокированный сайт не начинает загрузку.
- Отправка файлов сайтам (кнопка «+», `<input type=file>`) — «Разрешено» по умолчанию,
  настраивается в «Разрешениях сайтов».
- **PDF-вложения** (`Content-Disposition: attachment`), которые движок открывает в новом
  пустом окне, — скачивать как обычный файл. Не перезагружать адрес в исходной вкладке:
  на Android это давало бесконечный цикл.

## 5. Профили
- Главный экран: показывать **10** профилей, остальные под «Показать все профили (N)».
- **Отмечен выбранный профиль** (последний открытый): рамка акцентного цвета и галочка.
- **Закрепить профиль** (меню профиля «Закрепить»/«Открепить»): закреплённые всегда
  сверху списка, у имени значок булавки. Хранить отдельно от порядка.
- У каждого профиля **кнопка настроек** (шестерёнка) → экран профиля, где настраивается
  всё: имя, описание, закрепление, свои вкладки или общий набор, файлы профиля, очистка
  данных профиля.
- Порядок — перетаскиванием; меню профиля: Настройки профиля · Переименовать ·
  Закрепить · Выше · Ниже · Выйти и очистить.
- **В окне браузера** клик по чипу профиля (цвет + имя) открывает список профилей
  (цвет, имя, адрес почты, текущий отмечен) — выбор сразу переключает на другой профиль;
  внизу «Все профили» → главный экран.

## 6. Нижняя панель (у Windows — панель инструментов)
Кнопка «Очистить» заменена настраиваемой: в настройках выбрать, что на этом месте —
Скачанные файлы (по умолчанию) · Очистить данные · Избранное · Вкладки · Заметки ·
Сохранённые страницы · Поделиться · Найти на странице.

## 7. Запрет скриншотов
Переключатель «Запретить скриншоты» в «Конфиденциальность и безопасность», **по
умолчанию выключен**. Windows: `BrowserWindow.setContentProtection(true)` (окно чёрное
на снимках и при показе экрана).

## 8. Экран настроек
- Сверху поиск по настройкам (по заголовкам и подписям, «Ничего не найдено»).
- Главная страница настроек — группы с иконками и кратким содержимым, клик — раздел:
  1. Основные (язык, тема, поисковик, главная страница, браузер по умолчанию)
  2. Профили (количество, имена, общие вкладки, полоса профилей)
  3. Панели и вкладки (адресная строка сверху/снизу, скрытие при прокрутке,
     кнопка панели, живые вкладки)
  4. Конфиденциальность и безопасность (вход по паролю/Windows Hello, запрет
     скриншотов, только HTTPS, разрешения сайтов, проверка безопасности)
  5. Данные (кэш, история)
  6. Моя библиотека (заметки, сохранённые страницы, статистика)
  7. О приложении (справка и отзывы, о приложении)
- При вводе в поиск показываются подходящие разделы из всех групп.

## 9. Прочее, сделанное раньше (проверить, что есть)
Кнопка полного экрана · уведомления сайтов → системные уведомления с именем профиля ·
процент скачивания · статистика в настройках · первый запуск с профилями-примерами
(Личное, Работа, Покупки, Соцсети) и обучением · мгновенная смена языка везде ·
несколько вкладок в профиле · быстрый поиск на главном (открывает в выбранном профиле).

## 10. Позитивные фразы и приветствие
- 300 фраз на 10 языках: `app/src/main/assets/phrases/<язык>.txt` (строка N — одна и та же
  фраза на всех языках). Скопировать эти файлы в desktop как есть.
- Показ **случайный при каждом открытии** главного экрана и стартовой страницы, **без
  повторов**, пока не пройдут все 300 (перемешанная колода в настройках, позиция сохраняется;
  новая колода не начинается с последней показанной фразы).
- Над фразой — приветствие по времени суток: 5–11 «Доброе утро!», 12–16 «Добрый день!»,
  17–22 «Добрый вечер!», 23–4 «Доброй ночи!» (ключи `greet_morning/day/evening/night`).
- Тесты: в каждом файле 300 непустых строк без повторов; приветствие для 8, 13, 19, 2, 23 часов;
  300 показов подряд — все разные, на стыке колод нет повтора.

## 11. Личный кабинет профиля
Экран «Личный кабинет» (меню ⋮ → группа «Мои данные», меню профиля, настройки профиля):
- **Пароли** профиля: список (сайт, логин), меню: Показать пароль, Копировать логин,
  Копировать пароль, Изменить, Удалить; «Добавить пароль»; переключатель «Предлагать
  сохранять / Не предлагать»; список сайтов «Никогда для этого сайта» с удалением.
  Показ/копирование пароля — только после Windows Hello (`UserConsentVerifier`), если он настроен.
- После входа на сайт — вопрос «Сохранить пароль для site?»: Сохранить · Никогда для этого
  сайта · Не сейчас. В инкогнито не спрашиваем. Подстановка — только пароли профиля открытой
  вкладки; если аккаунтов несколько — выбор аккаунта. (Electron: свой content-script на формы
  входа + IPC; Chromium-менеджер паролей в Electron недоступен.)
- Хранение: зашифровано ключом ОС (`safeStorage.encryptString`, DPAPI), отдельно на профиль.
- **Наборы вкладок**: «Сохранить открытые вкладки (N)» с названием; список наборов (название,
  число вкладок, дата), Открыть (добавить вкладки к открытым) · Удалить.
- **Мои данные**: Избранное, Скачанные файлы, Заметки, Сохранённые страницы, Настройки профиля.
- **Резервная копия** в файл `.osbackup`: пароли, наборы вкладок, избранное, заметки, имя и
  описание профиля. Шифрование паролем пользователя (не короче 6 символов, ввод дважды):
  PBKDF2-HMAC-SHA256, 120 000 итераций, соль 16 байт → AES-256-GCM, IV 12 байт; формат JSON
  `{"app":"os-browser","v":1,"salt","iv","data"}` в base64 — **совместим с Android**, копию
  можно перенести между телефоном и компьютером. Восстановление добавляет недостающее без
  дублей и показывает, сколько чего восстановлено; неверный пароль — «Неверный пароль или
  повреждённый файл».
- Тесты: пароли раздельны по профилям и не хранятся открытым текстом; обновление по сайту+логину;
  поддомены; наборы вкладок без стартовых страниц; копия: неверный пароль → отказ, восстановление
  в другой профиль, без дублей избранного и заметок.

## 12. Широкие экраны, контакты, домен
- Экраны-списки (главный, настройки, загрузки, избранное, кабинет, разрешения сайтов) на широком
  окне — содержимое не шире 720 px и по центру; на узком — во всю ширину.
- Почта для связи и отзывов везде: **hello@os-browser.com** (в Android `HelpActivity.FEEDBACK_EMAIL`,
  в desktop `FEEDBACK_EMAIL` в `src/main/ipc.ts` — уже заменено).
- Сайт: **https://www.os-browser.com**, политика: `/privacy.html` (ru) и `/privacy-en.html` (en) —
  обновлена: пароли, резервная копия, Safe Browsing; для Windows добавить пункт про
  `safeStorage`/DPAPI вместо Android Keystore.

## 13. Страницы входа не перезагружаются сами
- При выгрузке давно не открытых вкладок (лимит «живых вкладок») **не выгружать** вкладки, где
  открыта страница входа или подтверждения кода (Apple ID, Google, Microsoft, OAuth, пути с
  `signin`, `login`, `2fa`, `two-factor`, `verify`, `challenge`, `mfa`).
- Такие адреса не запоминать как «последний адрес вкладки» — вкладка не должна открываться на
  форме входа после перезапуска.
- Причина: каждая перезагрузка страницы подтверждения отправляет новый SMS-код, и сайт (Apple)
  временно блокирует вход: «Отправлено слишком много кодов проверки».

## 14. История и удаление данных — как в Chrome
- **История** — отдельный экран (не диалог): заголовок, поиск, подсказка «История профиля …»,
  ссылка «Удалить данные о работе в браузере…», записи по дням («Сегодня — 25 окт. 2026 г.»,
  «Вчера — …», дата): буква сайта в кружке, заголовок, домен, крестик удаляет одну запись,
  нажатие открывает страницу новой вкладкой этого профиля.
- **Удалить данные о работе в браузере** — диапазон (15 минут, час, 24 часа, 7 дней, 4 недели,
  всё время) и карточки с галочками и счётчиками: История (вкл.), Cookies и данные сайтов (вкл.,
  для всего профиля), Кеш (вкл.), Вкладки (вкл.), Пароли (выкл.), Настройки сайтов (выкл.);
  пояснение «Избранное, заметки, сохранённые страницы и файлы не удаляются»; кнопка «Удалить данные».
- Пункт нижней панели/меню «Очистить данные» открывает этот экран.

## 15. Звук после нажатия
Видео со звуком, запущенное нажатием пользователя (плеер сайта вызывает play() позже касания),
не блокировать как автозапуск: в течение 10 с после касания страницы разрешать воспроизведение со
звуком, если сайт явно не заблокирован в «Разрешениях сайтов». (В Electron: `autoplayPolicy:
'user-gesture-required'` в webPreferences уже даёт такое поведение — проверить, что звук есть.)

## 16. Все изображения для магазина и сайта — 3:4
- Скриншоты и промо-изображения Windows-версии (Microsoft Store, сайт) — в пропорции **3:4**,
  вертикально: 1800×2400 (или 1200×1600). Окно браузера снимается и вписывается в рамку 3:4 с
  подписью сверху — тот же стиль, что у Android: `docs/play/tools/compose.js`, подписи —
  `docs/play/tools/captions.json` (10 языков, арабский справа налево).
- Снимать на 10 языках автоматически (Playwright + Electron), с подготовленными данными:
  профили-примеры, вкладки, история, заметки, загрузки, один пароль в кабинете.
- Исключения, где размер задан магазином жёстко: значок и баннеры магазина.

## 17. Выделение текста без «прыжков»
Пока выделен текст (или палец держит долгое нажатие), панели браузера не прячутся и не выезжают,
обновление жестом «потянуть вниз» не срабатывает — иначе страница сдвигается под пальцем и
выделение съезжает. (Windows: при выделении мышью/тачем не менять высоту панелей окна.)

## 18. Микрофон, камера, геолокация — можно «Разрешить»
- В «Разрешениях сайтов» для микрофона, камеры и геолокации три варианта: Спрашивать ·
  Разрешить · Запретить (раньше не было «Разрешить»).
- Если сайту запрещено — не молча: уведомление «Микрофон запрещён для site (настройки сайта)».
- Если доступ выключен в настройках системы (Windows: Конфиденциальность → Микрофон/Камера) —
  окно с объяснением и кнопкой «Открыть настройки» (`ms-settings:privacy-microphone`, `…-webcam`).
- Новые ключи: `perm_android_off`, `open_settings`.

## 19. Общий кабинет, генератор паролей, плитка и папки профилей
- **Общий личный кабинет** (кнопка с замком на главном экране): переключатель «Все профили» /
  каждый профиль; в режиме «Все» — сводка по профилям (пароли, наборы вкладок, файлы), поиск по
  паролям всех профилей, генератор, копия **всех** профилей одним файлом `.osbackup`
  (`{"v":2,"profiles":[{"id":N,"data":{…}}]}`; v1 восстанавливается в выбранный профиль).
- **Генератор паролей**: длина 8–32, цифры, знаки, без похожих символов (0/O, 1/l/I), оценка
  надёжности (слабый / средний / надёжный / очень надёжный), «Копировать» и «Новый»; в окне
  «Добавить пароль» — «Сгенерировать надёжный пароль».
- **Предложить надёжный пароль на сайте**: на формах регистрации/смены пароля (поле
  `autocomplete=new-password`, две строки пароля или адрес/форма с signup/register…) под полем
  кнопка «🔑 Предложить надёжный пароль» → пароль вставляется во все новые поля пароля, браузер
  потом предлагает его сохранить. Android: встроенное расширение `app/src/main/assets/pwgen/`
  (можно взять тот же JS как content script/preload в Electron).
- Язык сайтов (Accept-Language) = язык приложения.
- **Профили плиткой или списком** (переключатель у заголовка «Профили»): плитка — 2 колонки
  (4 на широком окне), кружок с буквой, имя, почта, значки «закреплён»/«текущий», шестерёнка.
- **Папки профилей**: меню профиля «В папку» (существующая / новая / без папки); на главном —
  разделы по папкам (по алфавиту, «Без папки» последним), папка сворачивается, долгое нажатие —
  переименовать / убрать папку (профили остаются).

## 20. Документы открываются в Оси
Word (DOCX), Excel (XLSX — все листы), PowerPoint (PPTX — по слайдам), OpenDocument (ODT, ODS,
ODP) и CSV открываются прямо во вкладке Оси: файл превращается в HTML-страницу на устройстве
(заголовки, жирный/курсив/подчёркнутый, списки, таблицы, картинки DOCX), без интернета и сторонних
сервисов. Так открываются скачанные файлы и файлы профиля. Образец — `DocView.kt` и его тесты
`DocViewTest`. Старые DOC/XLS/PPT — «Открыть с помощью».

## 21. «Покинуть страницу?» и повторная отправка формы
- Запрос сайта beforeunload: окно «Покинуть страницу? Внесённые изменения могут не сохраниться» —
  Покинуть / Остаться. Если со страницей не работали больше 3 минут — уходим без вопроса.
